EXECUTIVE SUMMARY
-----------------

It contains four HTML pages, one shared stylesheet, one shared JavaScript file,
and local image/video assets. The front-end presentation and prototype

authentication, database, POS transaction engine, inventory engine, HRMS,

LEAD FORM / EXTERNAL INTEGRATION STATUS
---------------------------------------
The main and POS pages contain a form with id=leadForm. script.js submits a
FormData payload to an external Google Apps Script URL using fetch POST with
mode="no-cors".

Status: Wired at source level, not end-to-end verified.

Important implications:
- no-cors prevents the browser from reading the response, so the current code
  treats a completed fetch promise as success even if the remote endpoint does
  not process the lead as intended.
- There is no server-side code in this repository to inspect or maintain the
  endpoint.
- There is no spam protection, rate limiting, consent record, validation beyond
  required fields, retry queue, or observable delivery confirmation.
- The hospitality page has no lead form and does not use the lead submission
  path.
